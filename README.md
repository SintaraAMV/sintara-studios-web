# Sintara Studios Web

Initial static website for `sintara-studios.com`.

## Stack

- HTML
- CSS
- vanilla JavaScript

This is intentional. The current site does not require a server runtime or framework.

## Pages

- `index.html` — Sun / Black Hole portal
- `studio.html` — Sintara Studios area
- `projects.html` — Projects / Services area
- `rango-b.html` — Rango B commercial page

## GitHub Pages

Recommended flow:

1. create repository `SintaraAMV/sintara-studios-web`
2. upload these files
3. enable GitHub Pages from the `main` branch
4. verify the temporary GitHub Pages URL
5. configure `sintara-studios.com`
6. only then update GoDaddy DNS
