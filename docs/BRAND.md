# BRAND — Sintara Studios

## Architecture

Sintara has two visible worlds:

1. **Studio / Sun**
   - company identity
   - products
   - games
   - original work

2. **Projects / Black Hole**
   - technical services
   - Rango B
   - Rango A
   - future project work

The two areas belong to one brand but should not be visually confused.
